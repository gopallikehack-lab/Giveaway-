# 🎁 Premium Telegram Giveaway Bot

A professional, feature-rich Telegram giveaway bot with admin panel, user management, and Vercel deployment support.

## ✨ Features

- 🎁 **Giveaway Management**: Create, manage, and delete giveaways
- 👥 **User Tracking**: Full user details with Telegram IDs
- 🔐 **Admin Panel**: Secure admin access for 2 admins only
- 📊 **Statistics**: View bot analytics and user data
- ⏰ **Scheduled Giveaways**: Set start and end times
- 🏆 **Multiple Winners**: Support for multiple winners per giveaway
- 🎟️ **Entry System**: Unique entry numbers for participants
- 📱 **Vercel Ready**: Optimized for serverless deployment

## 🚀 Deployment on Vercel
